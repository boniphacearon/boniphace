# BONIPHACE — Your Personal AI Assistant

A complete, installable Progressive Web App (PWA) personal AI assistant.

## Features
- ✅ Natural-language chat with context memory
- ✅ Free AI via Puter.js (no API key required)
- ✅ Installable PWA (Add to Home Screen on mobile)
- ✅ Simple / Deep answer-depth toggle
- ✅ English + Kiswahili
- ✅ Voice input (Speech-to-Text) + TTS
- ✅ File upload (PDF, DOCX, TXT, CSV, XLSX, images, code)
- ✅ Memory system ("remember that...", "forget that...")
- ✅ Tool architecture (web search, calculator, weather) with confirmation flow
- ✅ Projects workspace
- ✅ Markdown rendering with code copy buttons
- ✅ Sources/citations
- ✅ Full authentication (signup, login, JWT)
- ✅ Isolated per-user data (SQLite)
- ✅ Rate limiting, helmet, input validation
- ✅ Dashboard, Settings, Memory, Tools views
